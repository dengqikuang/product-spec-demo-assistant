# Contributing

Thanks for helping improve Product Spec & Demo Assistant.

## Before opening a pull request

1. Keep the three-column demo framework and its locked sections intact.
2. Put reusable system-shell changes under `assets/system-shells/<system-id>/`.
3. Update `SKILL.md` and relevant references when behavior changes.
4. Run `npm test` and include the result in the pull request.

## Proposing a system shell

Include the intended terminal or product system, viewport, reusable navigation
rules, and a minimal demo state that exercises the shell. Do not include real
user data, confidential screenshots, credentials, or proprietary assets.
